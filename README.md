# AttendX Test Scripts

## Project Description
This repository contains sample test scripts for the
AttendX student attendance application.

## Test Scripts

1. login_test.py
   - Checks valid login test data.
   - Checks empty login fields.

2. attendance_marking_test.py
   - Checks attendance data.
   - Checks invalid attendance status.

## Requirements
- Python 3
- Git

## Execution
Run the scripts using:

python login_test.py
python attendance_marking_test.py

## Version Control
Git is used to track file changes, and GitHub
is used to share the repository with the QA team.


## Team Collaboration
Test scripts are maintained using Git and GitHub.
Team members should pull the latest changes before
starting their work.
